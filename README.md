# AULA/DEPT — Frontend académico

Proyecto de maquetación frontend inspirado en la página **Basic** de Frontend Practice y adaptado a una temática relacionada con clases, proyectos académicos y trabajo en equipo.

## Tecnologías utilizadas

El sitio fue desarrollado únicamente con tecnologías frontend:

- HTML
- CSS
- JavaScript
- Diseño responsive
- Animaciones al hacer scroll
- Efectos `hover`
- Menú adaptable para dispositivos móviles
- Carrusel horizontal interactivo
